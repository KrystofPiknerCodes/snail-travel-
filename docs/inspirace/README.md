# Inspirace — DESIGN.md sbírka

`design-md/` je kopie [VoltAgent/awesome-design-md](https://github.com/voltagent/awesome-design-md)
(commit `fcc7028`, staženo 11. 11. 2026, licence MIT — viz `design-md/LICENSE`).
84 rozborů vzhledu známých webů ve formátu DESIGN.md (barvy, typografie, rozestupy,
komponenty, pravidla).

**Slouží jen jako inspirace při psaní webu, ne jako předloha ke kopírování.**
Vlastní design Snail Travel (zlatá z loga, Playfair / Cormorant / Inter, Cinzel jen
na dvou místech, světlý editorial, světlé fotky) je v `CLAUDE.md` a má vždy přednost.
Převzít jde princip (jak pracují s fotkou, bílým místem, hierarchií, detailem karty),
ne barvy, fonty ani identitu cizí značky.

## Co se k luxusní cestovce hodí nejvíc

- `airbnb/` — karty ubytování, detail místa, práce s fotkou, cestovní kontext
- `apple/` — klid, velké fotky, jeden důraz na obrazovku
- `bugatti/`, `ferrari/`, `lamborghini/`, `bmw/` — luxusní značky, prémiový tón
- `tesla/`, `spacex/` — full-screen hero, minimum prvků přes fotku
- `wired/`, `theverge/` — editorial typografie, delší texty
- `starbucks/`, `nike/` — spotřebitelská značka s emocí

Ostatní (fintech, dev tools, SaaS) jsou pro tenhle web spíš mimo.
